# Задание 1. Разбор tsconfig.json

Откройте `tsconfig.json` в корне проекта и для каждой строки напишите
**своими словами**, что она делает. Не копируйте документацию —
объясните так, как будто рассказываете одногруппнику.

## compilerOptions

### target
> Версия JavaScript, в которой TypeScript должен сгенерировать свой код

### module
> Формат модулей в скомпилированном коде, например ESNext оставляет современный синтаксис import и export

### moduleResolution
> Определяет, как TypeScript ищет файлы при импорте, 
    например режим `bundler` позволяет импортировать файлы без указания расширения .ts или .js

### strict
> Включает набор строгих проверок типов одной настройкой

### strictNullChecks
> Не даёт считать `null` и `undefined` обычными значениями любого типа

### esModuleInterop
> Позволяет импортировать CommonJS-модули через обычный import

### skipLibCheck
> Пропускает проверку типов внутри файлов библиотек из зависимостей

### forceConsistentCasingInFileNames
> Требует одинаково писать регистр букв в имени файла и в путях импорта

### outDir
> Указывает папку `dist`, куда TypeScript положит скомпилированные JavaScript-файлы при обычной сборке

### rootDir
> Указывает корень исходных файлов проекта

## include
> Перечисляет файлы, которые TypeScript должен включить в проект

## exclude
> Перечисляет файлы, которые TypeScript НЕ должен включить в проект

# Задание 1.2. Включение флагов

Для каждого пункта ниже:
1. Определите, какой флаг нужно поменять в `tsconfig.json`.
2. Внесите изменение.
3. Запустите `npm run check`.
4. Запишите результат в `task1.md`.

---

### 1. Строгие проверки типов
Включите опцию, которая делает `null` и `undefined` отдельными типами,
а не «совместимыми со всем». Без неё код с `null` компилируется, с ней — нет.

**Ваш ответ:** `strictNullChecks`

---

### 2. Проверка `this`
Включите опцию, которая ругается, если внутри функции используется `this`,
но функция не является методом класса (то есть `this` не определён).

**Ваш ответ:** `noImplicitThis`

---

### 3. Неявный `any`
Включите опцию, которая ругается, если переменная получает тип `any`
автоматически (например, функция без аннотаций параметров).

**Ваш ответ:** `noImplicitAny`

---

### 4. Возврат из функции
Включите опцию, которая требует, чтобы **все** ветки функции возвращали значение,
если функция объявлена как возвращающая не-`void`.

**Ваш ответ:** `noImplicitReturns`

---

## Результат `npm run check`

Проверка запущена после включения всех четырёх флагов. Она завершается с
ошибками в незавершённых заданиях 3, 4, 5 и 6: в заданиях 3 и 5 функции пока
не возвращают значения, а файлы заданий 4 и 6 ещё не экспортируют требуемые
функции
